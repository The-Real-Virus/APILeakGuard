# APILeakGuard v1.0 release candidate

Windows 10 and 11 x64 are build targets. Verification evidence and open checks are tracked in the release ledger. See [remaining tests](docs/REMAINING-TESTS.md) for the compatibility matrix and provider checks.

The local candidate bundles the Python runtime, PySide6 desktop and console CLI in one portable ZIP. It includes offline response and log analysis, approved functional HTTP suites, built-in field and header checks, JSON and YAML policies, HTML, CSV and JSON reports, and a local JSON fix workflow. The optional assistant starts disabled and supports plain-language chat, conversation history, and reviewed in-app actions.

Artifacts are unsigned. Compare their SHA-256 checksums with the manifest before using a local build. Release and publication require owner approval.

The revised portable build adds a local practice request, a manual form with the full endpoint URL and a Bearer token field, and plain-language connection and HTTP status feedback. Imported definitions can use a reachable VM base URL for a selected private HTTP lab request. Gemini discovery prioritizes compatible text models, and the assistant can load a provider key privately from a local text file.

Chat keeps the composer and proposed actions visible while the page scrolls. If the provider request fails, the app gives specific connection guidance and keeps the draft ready for another send. Starting a plan from definitions now proceeds directly from choosing the first file to entering its base URL.
